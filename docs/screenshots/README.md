# Screenshot Guidelines

Nama file (harus):

- `dashboard.png` — Dashboard
- `list.png` — Daftar Resep
- `detail.png` — Detail Resep
- `add_recipe.png` — Tambah Resep / Tambah Tugas

Rekomendasi ukuran & format:

- Format: `png` atau `jpg`
- Lebar: 800–1280 px (rasio aspek portait/landscape sesuai tampilan)
- Optimalkan ukuran file agar tidak terlalu besar (≤ 500 KB setiap file)

Tambahkan file ke folder `docs/screenshots` lalu commit.
