# Dokumentasi Proyek

Folder ini berisi panduan singkat terkait dokumentasi proyek.

## Screenshots

Simpan screenshot aplikasi di `docs/screenshots` dengan nama file:

- `dashboard.png`
- `list.png`
- `detail.png`
- `add_recipe.png`

File ini hanya berfungsi sebagai panduan. Untuk menampilkan screenshot di README utama, gunakan path `docs/screenshots/<name>.png`.
